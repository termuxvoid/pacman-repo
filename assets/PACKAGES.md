# TermuxVoid Pacman Package Catalog

## Overview

The complete catalog of packages available from the **TermuxVoid pacman repository**. Each tool is listed with a link to its documentation page and a short description. All packages install on your device at install time — nothing pre-compiled.

> [!NOTE]
> The same tools are also available as classic APT packages: [github.com/termuxvoid/repo](https://github.com/termuxvoid/repo) (`curl -sL https://github.com/termuxvoid/repo/raw/main/install.sh | bash`).


**220+ packages** across 17 categories.
